TERRITORY FORGE V8 — GLOBAL MODAL SYSTEM

Что изменено:
- Добавлена единая системная обработка обычных окон/модальных экранов.
- Обычные окна получают корректный scroll/overscroll и безопасные зоны Telegram WebView.
- При открытом окне блокируется фон от случайного вертикального overscroll.
- Система автоматически подхватывает динамически создаваемые окна.
- Arena полностью исключена из V8.
- Существующий единый чёрный круг с белым крестиком V6/V7 сохранён.
- Дизайн содержимого окон не переписывался, чтобы не ломать рабочие экраны.

Установка:
1. Замени содержимое frontend-проекта файлами из ZIP.
2. Commit в main.
3. Дождись Render Deploy.
4. Полностью закрой Telegram Mini App и открой заново.
5. Проверь профиль, кузницу, игровые окна. Arena не проверяем этим релизом.
