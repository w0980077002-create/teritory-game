S97 — ЭКРАН ПЕРСОНАЖА
=======================

Единый мобильный экран:
- уровень и XP;
- Сила;
- Ловкость;
- свободные очки;
- прокачка +1;
- сброс распределения;
- оружие;
- броня;
- пояс;
- сила атаки;
- максимальный HP;
- крит;
- уклонение.

Подключение:
<script src="s97-character-screen.js?v=97"></script>

Открытие:
window.openTerritoryS97(playerId)

Экран использует существующие S90/S96 API и не хранит отдельную
копию характеристик.
