10038 — ИНТЕГРАЦИЯ 240 ГЛАВ

Заменяет старую логику карты/этапов на единую data-driven систему chapters-240.json.

Цепочка:
☠️ Карта глав → 4 этапа → PvE → +25% → следующий этап → 100% → Босс → Глава завершена → Следующая глава.

ВАЖНО:
- Арена НЕ изменяется и не используется вместо PvE.
- 4-я нижняя кнопка по смыслу карты: существующая кнопка/позиция не переназначаются.
- ☠️ карта доступна из HOME и прямо во время PvE/Босса.
- 240 глав идут одной системой; отдельные экраны на каждую главу не создаются.
- Состояние сохраняется через TerritoryStore/localStorage текущего приложения.
