TERRITORY — CLEAN VIP + ALEX QUEST

Оставляется только ОДИН новый файл:
- vip.js

Что делает:
- добавляет задание именно Алекса на городском экране;
- условие задания: 5 побед на Арене;
- прогресс берётся из существующей статистики Arena;
- после 5 побед Алекс выдаёт VIP на 10 дней;
- состояние сохраняется в localStorage;
- никаких технических надписей для игрока нет;
- Arena, app.js и systems-v145.js не переписываются.

Подключение:
В index.html после:
<script src="app.js?v=138"></script>
<script src="arena.js?v=139"></script>

добавить:
<script src="vip.js?v=1"></script>

Старые файлы:
- vip-quest.js
- vip-quest.css
- alex-vip-quest.js
- alex-vip-quest.css

не нужны. Их можно удалить из репозитория.
