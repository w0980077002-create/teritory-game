Territory G40 — restored visual base

This build restores the approved Sdolars City visual reference shown in the project library:
- full vertical Territory home screen
- Duke Alex + player warrior scene
- top resources/HUD
- left and right city actions
- bottom six actions: Бой / Арена / Инвентарь / Экипировка / Задания / Карта

G40 Character Core is included as development-core.js from the preserved G40 patch.

IMPORTANT: G40.zip itself was only a patch and did not contain the full frontend. This package combines the preserved frontend files with the approved visual reference so the phone build has a complete runnable base.
