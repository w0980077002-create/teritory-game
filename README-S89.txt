S89 — ЗАДАНИЯ + ПРОГРЕССИЯ
===========================

Добавляет постоянный игровой цикл:
PvP → победа → прогресс задания → награда → XP/монеты → уровень.

Задания:
1. Первая кровь — 1 победа — 40 XP + 120 монет.
2. Боец Сдоларса — 3 победы — 120 XP + 350 монет.
3. Ветеран арены — 10 побед — 450 XP + 1000 монет.

Также:
- победы сохраняются в pvpWins;
- задания сохраняются в профиле;
- награда забирается только один раз;
- XP автоматически переводит персонажа на следующий уровень;
- прогресс не теряется после перезапуска сервера.

API:
GET  /api/quests?id=PLAYER_ID
POST /api/quests/claim {questId}

Перед изменением server.js создаётся server.js.s88-backup.
