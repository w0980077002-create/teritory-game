TERRITORY PASS 36 — INVENTORY COMPARE / ONE-TAP EQUIP

Что добавлено:
- В PvE-добыче теперь нажатие по предмету открывает отдельное сравнение с текущим предметом в этом слоте.
- Показываются 4 базовых стата: Атака, Защита, Ловкость, Max HP и разница +/-.
- Кнопка «Надеть» сразу меняет предмет в canonical TerritoryStore.equipment.
- Старый предмет возвращается в inventoryItems, новый удаляется из добычи.
- Сохраняется через TerritoryStore.saveNow(), UI получает стандартное событие state-changed.
- Arena-ссылка на заменённый предмет очищается, чтобы не оставить старый id в пресете.
- Существующий PASS 33/35 progression + home equipment layer сохранён: заменены только уже подключенные territory-progression-core.js/css.

Установка:
1. Не удаляй проект.
2. Распакуй ZIP поверх текущего репозитория.
3. Заменятся только 2 уже подключенных файла + README.
4. Открой Инвентарь → Добыча PvE → нажми предмет → увидишь сравнение → «Надеть».

Примечание: ZIP не делает запись в GitHub автоматически.
