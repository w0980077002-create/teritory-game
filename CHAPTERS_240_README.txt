# 240 CHAPTERS 10037

Не создаём 240 отдельных экранов.
Создаём ОДИН движок + chapters-240.json.

Каждая глава содержит:
- уникальное название;
- 4 этапа;
- обычных врагов;
- усиление HP/урона;
- босса;
- усиление HP/урона босса;
- прогресс 25% за пройденный этап;
- босс при 100%.

После победы над боссом текущая глава автоматически переключается на следующую.
Всего 240 глав.

Преимущество:
- один код;
- одна карта;
- одна PvE система;
- одна Boss система;
- данные всех 240 глав лежат в одном JSON;
- дальше можно менять названия/баланс без переписывания экранов.

Важно: 10037 — это фундамент данных/прогрессии. Старые визуальные системы Arena/PvE/Home не должны переписывать под 240 копий.
