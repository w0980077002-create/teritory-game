S86 — настоящая тактическая защита Territory
==============================================

Что сделано:
- 4 зоны боя: Голова / Грудь / Пояс / Ноги.
- За ход выбирается ровно 1 зона атаки.
- За ход выбираются ровно 2 разные зоны защиты.
- Сервер теперь принимает defenseZones как массив.
- Старый формат defense="zone" поддержан для совместимости, но для нового боя клиент должен отправлять defenseZones.
- Сервер отклоняет ход, если выбрано не ровно 2 защиты.
- Сервер отклоняет атаку, если атакуемая зона одновременно выбрана в защите.
- Перед изменением server.js создаётся server.js.s85-backup.

Применение:
1. Положить apply-s86.js рядом с server.js.
2. Запустить: node apply-s86.js server.js
3. Подключить s86-tactical.js в игру.
4. Вызов API /api/pvp/action отправлять с полями:
   { matchId, zone: "head", defenseZones: ["legs","belt"] }

Важно:
Это патч именно поверх существующего server.js. Он не заменяет index.html и не трогает рабочую основу игры.
