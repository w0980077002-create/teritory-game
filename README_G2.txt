G2 — VIP PANEL
================

Это патч для GAME repo `w0980077002-create/teritory-game`.

Что добавлено:
- маленькая кнопка VIP под блоком профиля на главной;
- отдельное VIP-окно в стиле Territory/Sdolars;
- VIP 0 по умолчанию;
- список VIP-возможностей;
- заготовка для VIP-наборов;
- `TerritoryVIP.canAutoBattle()` возвращает true только при активном VIP;
- покупка пока НЕ подключена к платежам — это будет отдельным серверным этапом.

Установка:
1. Добавь `vip.js` в корень GAME repo.
2. В `index.html`, перед `</body>`, добавь:
   <script src="vip.js?v=1"></script>
3. Не удаляй существующие файлы.
4. После загрузки в GitHub подожди деплой и открой игру заново.

Важно:
- текущий рабочий город не заменяем;
- Cloudflare backend не меняем;
- токены и секреты в этот ZIP не входят.

Для будущего автобоя:
- VIP 0 -> автобой закрыт;
- VIP 1+ -> функция технически разрешена;
- окончательную проверку VIP позже перенесём на сервер.
