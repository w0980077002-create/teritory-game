TERRITORY FORGE V19 — CLEAN INTERACTION CORE

Цель:
Перестать чинить интерфейс слоями из pointer/touch/click/coordinate обработчиков и перейти на один понятный канал взаимодействия.

Что изменено:
- Убраны дублирующие pointerup/touchend обработчики главного города.
- Убраны глобальные coordinate hit-tests.
- Убраны касания, которые одновременно запускали несколько close-систем.
- Обычные модалки больше не закрываются тапом по затемнённому фону.
- Закрытие обычных окон идёт через один click-путь.
- Единый чёрный круг + белый крестик сохранён.
- Профиль/кузница получают крестик автоматически.
- Arena не переделывается и не является целью этого релиза.
- Backend не изменён.

Главная идея V19:
Один пользовательский тап = одно действие.
Никаких координатных угадываний и параллельных touch/click обработчиков.
