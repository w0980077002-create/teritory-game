S92 — ВИЗУАЛЬНЫЙ ТАКТИЧЕСКИЙ PvP
===================================

Добавляет отдельный мобильный боевой экран:
- два бойца и HP;
- визуальные полосы здоровья;
- выбор 1 зоны атаки;
- выбор ровно 2 зон защиты;
- блокировка атакуемой зоны в защите;
- журнал боя;
- визуальный flash-эффект при ударе;
- отправка defenseZones на существующий PvP API.

Файл:
s92-pvp.js

Подключение:
<script src="s92-pvp.js?v=92"></script>

Открытие из существующего интерфейса:
window.openTerritoryS92(match)

match должен быть объектом /api/pvp/mine или /api/pvp/accept.

Важно:
Это UI-слой. Он не заменяет существующий index.html.
Для реального уклонения/двух блоков сервер должен быть установлен
из S86/S91.
