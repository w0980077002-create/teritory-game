# Teritory Game — MAP + MOVEMENT + ENCOUNTER 10028

Это первый готовый игровой блок.

## Что уже работает
- экран КАРТА;
- глава/этап берутся из `window.TerritoryStore.state`;
- герой и спутник двигаются вправо;
- фоновые слои двигаются влево с параллаксом;
- бот появляется справа и идёт навстречу;
- происходит встреча;
- появляется кнопка `В БОЙ`;
- `В БОЙ` передаёт сцену в существующий Arena;
- нижняя навигация на карте уже закреплена;
- №45 логически остаётся `КАРТА`.

## Важно
Это именно механический блок №1. Арт карты пока не заменяется на финальную рисованную локацию. Визуальные слои сделаны отдельно, чтобы затем подставить оригинальный игровой фон без переделки механики.
