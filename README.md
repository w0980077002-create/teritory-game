# Territory — Sdolars — S77

S77 — полноценное обновление текущей ветки Territory, а не новая игра.

## Бой
- Ровно 4 зоны: Голова, Грудь, Пояс, Ноги.
- Атака: 1 зона.
- Защита: 2 зоны.
- Новый боевой экран: HP, раунд, журнал, выбор зон, явная кнопка удара, автобой.
- Убран «Живот» и старый пятизонный интерфейс.

## Технически
- Worker содержит актуальный index.html S77.
- HTML отдаётся с no-store.
