# Territory — Sdolars / v1

Это самостоятельный мобильный прототип, сделанный как новая рабочая база.

Главный принцип:
- игровой мир занимает основной экран;
- HUD и быстрые действия находятся поверх мира;
- «Арена» — отдельный режим;
- только «Арена» использует тактический выбор зон;
- остальные режимы не используют зоны головы/груди/живота/пояса/ног.

## Запуск
Открой `index.html` в браузере телефона или размести папку как статический сайт.

Сохранение:
`localStorage` → ключ `territory_save_v1`.
