# Territory — S64 PVP LEAGUE

База: рабочая S63. S61/S62/S63 не заменяются.

## Что добавлено
- Полноценная локальная PvP-лига с рейтингом и дивизионами.
- 6 соперников с разной силой и наградами.
- Лимит 5 PvP-боёв в день.
- Рейтинг растёт за победы и снижается при поражении.
- Серия побед и лучший результат сохраняются.
- PvP использует существующую тактическую механику S62: 1 зона атаки + 2 зоны защиты.
- Награды PvP идут в существующий прогресс игрока.
- Вход в PvP добавлен из Арены и Профиля.
- GitHub остаётся способом публикации игры; сервер/Cloudflare не добавлялись.

## Проверка
Все JS-блоки проверены Node.js --check.
