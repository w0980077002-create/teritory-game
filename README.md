# Territory — Sdolars / s15

Рабочая интерактивная версия.

Главное:
- это HTML/JS игра, не картинка;
- город используется только как фон игровой сцены;
- один набор настоящих интерактивных кнопок: Замок, Арена, Районы, Таверна, Рынок, Game;
- старые дублирующие quick/live-locations блоки удалены;
- `Казино` переименовано в `Game`;
- фон слегка анимируется и имеет снег;
- Cloudflare / Worker / Wrangler / Three.js CDN отсутствуют.

Загрузка: заменить `index.html` в GitHub и сохранить папку `assets` рядом с ним.
