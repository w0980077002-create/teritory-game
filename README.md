# Territory s22

Главный экран сделан как полноэкранная мобильная игра:
- городская сцена занимает весь экран;
- воин находится непосредственно в сцене;
- UI — отдельные реальные HTML-кнопки поверх фона;
- патруль компактный;
- справа только уникальные локации;
- Арена одна и по центру над чатом;
- нижний ряд не дублирует правое меню;
- фон резкий, без CSS blur;
- Game вместо Казино;
- Cloudflare / Worker / Wrangler не используются.

Для GitHub достаточно загрузить `index.html`.
