# Territory — Sdolars s53

Новая контрольная сборка Territory для Telegram Mini App.

## Что сохранено и исправлено

- Sdolars, глава 5, уровни/опыт/характеристики.
- Полноэкранный вертикальный мобильный интерфейс.
- Взрослый визуальный стиль и сцена города.
- Тактический PvE-бой: 1 зона атаки + 2 зоны защиты из 5.
- Персонаж и противник видимы в бою.
- Исправлена анимация попадания персонажей.
- PvP/онлайн-игроки и дуэли с визуальными персонажами.
- Общий чат + чат клана, онлайн-список и WebSocket `/ws`.
- Серверное сохранение через Durable Object + SQLite.
- Инвентарь, экипировка, магазин, кузница, таверна, события, задания.
- Русский/английский язык.
- Ежедневные награды и прогресс.
- Добавлено отдельное виртуальное казино на внутриигровые монеты.
- Исправлены синтаксические ошибки в поздних клиентских модулях.
- Версия сборки: s53.

## Файлы

- `worker.js` — основной Cloudflare Worker с встроенной страницей игры и серверной логикой.
- `index.html` — отдельная копия клиентской страницы для контроля исходника.
- `wrangler.jsonc` — конфигурация Worker + Durable Object.
- `package.json` — зависимости/команда deploy.

## Важно

Эту сборку загружать в корень GitHub-репозитория, не удаляя рабочую Telegram Mini App URL.

После деплоя проверять:
1. Город.
2. Бой — должны быть видны оба персонажа.
3. Чат — общий/клановый и статус LIVE.
4. Инвентарь/экипировку.
5. Ещё → Казино.
6. RU/EN.
