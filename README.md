# Territory — S62 CORE GAMEPLAY

База: рабочая версия S61. S61 не заменяется и не удаляется.

## Что добавлено в S62
- Усилена основная арена: 8 ступеней противников вместо 4.
- Сложность противников растёт по мере побед.
- Сохраняется тактическая схема S61: выбор 1 зоны атаки + 2 зон защиты.
- Урон учитывает оружие, силу, навыки, броню и критический удар.
- Поражения и победы теперь ведут отдельную статистику.
- Серия побед влияет на награду.
- Победа даёт масштабируемые монеты и XP.
- Добавлен шанс боевого трофея, который попадает в существующий инвентарь.
- Получение нового уровня выдаёт свободные очки характеристик.
- В профиль добавлена «Статистика боёв».
- Существующие системы S61 не удалялись и не заменялись.

## Проверка
JS-код всех 27 script-блоков проверен через Node.js `--check` — синтаксических ошибок нет.
