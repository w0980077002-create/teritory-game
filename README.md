Territory — Sdolars v15

Главный экран заменён на реальную детализированную сцену Sdolars.
Сцена встроена в проект как sdolars_final_scene.png.
Поверх изображения находятся прозрачные рабочие зоны переходов: Арена, Рынок, Инвентарь, Районы, Game, Оружие и нижняя навигация.
На главном экране старый CSS-мир и обычный HUD скрываются, чтобы изображение показывалось как единый готовый игровой экран.
