# Territory — Sdolars — GitHub version

Эта версия предназначена для размещения только через GitHub Pages.

В проекте удалены Cloudflare Worker, Wrangler-конфигурация и серверный WebSocket-контур. Игра работает как статическая мобильная Web App с сохранением состояния в браузере.

## Файлы
- index.html — игра
- .nojekyll — отключает обработку Jekyll

Казино отсутствует. Тактический бой сохраняется: 1 зона атаки + 2 зоны защиты.
