# Territory — Sdolars v20

Финальный главный экран на реальной сцене Sdolars.

Изменение v20: нижняя навигация зафиксирована внутри игрового экрана, равномерно распределена по 5 блокам и больше не должна «уезжать» или обрезаться на мобильном экране.

Сцена остаётся резкой. Анимации живого города — только локальные и ненавязчивые.
