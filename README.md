# Territory — S63 GLOBAL GAMEPLAY

База: рабочая S62 с рюкзаком. S62 не заменяется и не удаляется.

## S63
- Районы превращены в прогрессируемую систему с требованиями по уровню, опасностью и активностями.
- Активности районов расходуют энергию, дают монеты/XP и трофеи.
- Для районов добавлен отдельный вход в тактический бой с подходящим уровнем противника.
- Добавлены ежедневные контракты: охота, исследование города, продажа добычи.
- Добавлена экономика S63: продажа районных трофеев и покупка улучшенного снаряжения.
- Покупаемое улучшенное снаряжение попадает в существующий рюкзак.
- Профиль дополнен общим прогрессом героя.
- Основной цикл связан: район → активность/бой → награда → трофей → рюкзак → продажа/экипировка → следующий район.
- Существующая тактическая арена S62 сохранена.
- GitHub остаётся текущей схемой работы; Cloudflare в S63 не используется.

## Проверка
Все script-блоки проверены через Node.js --check.
