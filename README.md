# Territory — Sdolars / s11 GitHub Interactive City

Это настоящая интерактивная HTML/JS-игра, а не скриншот.

## Что изменено
- Добавлен детализированный художественный фон города Sdolars как игровой asset.
- HUD и все кнопки остаются настоящими HTML-элементами.
- Добавлены кликабельные точки: Замок, Таверна, Рынок, Арена, Районы, Казино.
- NPC на сцене интерактивный.
- Фон слегка анимируется, создавая ощущение живой сцены.
- Существующая игровая логика и localStorage сохранены.

## GitHub only
Всё работает из `index.html` и папки `assets`.
Cloudflare, Worker, Wrangler и серверные зависимости отсутствуют.

Загрузить в корень `main`, сохранив папку `assets`.
