# Territory Sdolars v40 — Living Districts

v40 продолжает v39 и добавляет игровую карту районов Sdolars.

- Центр, Порт и Руины стали интерактивными локациями.
- Выбор района показывает его описание и награду.
- Кнопка «Отправиться» выдаёт монеты, XP и репутацию города.
- Уровень персонажа сохраняется через существующий localStorage.
- Автоматический городской спам, Alex Quest и торговец сохранены.
- Arena остаётся отдельной тактической системой.
