# Territory S107 — интеграция существующей игры

Основа: загруженный пользователем `index.html` + проверенный клиент S106, без переписывания игры с нуля.

Включено:
- живой экран Sdolars и персонаж в сцене;
- HUD HP / монеты / уровень;
- движение джойстиком и интерактивные здания;
- персонаж, рюкзак, экипировка и выбрасывание;
- рынок: покупка и продажа;
- квесты и награды;
- районы Sdolars;
- арена и тактический PvP: 4 зоны, 1 атака + 2 защиты;
- сила, ловкость, крит и уклонение;
- гильдии, приглашения, роли и участники;
- люди Сдоларса, друзья и PvP-вызовы;
- Telegram Web App API и серверная сохранность данных.

Запуск:
`npm install`
`npm start`

Проверка:
`npm run check`
