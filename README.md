# Territory — Sdolars / s18

Экран сделан по утверждённому визуальному референсу, но реализован как настоящая HTML/JS игра.

- резкая городская сцена без размытия;
- справа только уникальные: Замок, Районы, Таверна, Рынок, Game;
- Арена одна и находится по центру непосредственно над чатом;
- нижняя навигация не дублирует Арену;
- кнопки компактные и полупрозрачные;
- фон встроен в `index.html`;
- Cloudflare / Worker / Wrangler / Three.js CDN отсутствуют.
