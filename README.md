# Territory — Sdolars v16 LIVE

Главный экран использует реальную сцену Sdolars и поверх неё анимированный слой: лёгкое движение камеры, флаги, огонь/угли, дым, прохожие, птицы, дождь и свечение фонарей. Кнопки остаются отдельными кликабельными зонами.

Game вместо казино. Арена сохраняет тактические зоны атаки/защиты.
