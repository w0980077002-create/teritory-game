# Territory — Sdolars v36

Живой город с автоматическим потоком случайных событий.

- События появляются автоматически.
- Одновременно отображается только одно событие.
- После выбора следующая встреча появляется автоматически.
- Добавлены разные типы городских событий и редкое событие.
- Награды дают монеты и XP; повышение уровня сохраняется.
- Арена остаётся отдельным режимом с 5 зонами атаки и 2 зонами защиты.
