# Territory — Sdolars / s13

Визуальный экран переделан по последнему референсу, но это остаётся настоящая HTML/JS-игра.

- изображение используется только как фон игровой сцены;
- HUD, кнопки, навигация и точки локаций — реальные HTML/JS;
- повторяющиеся надписи внутри старого UI убраны;
- «Казино» переименовано в `Game`;
- добавлены живые интерактивные точки Замок / Арена / Районы / Таверна / Рынок / Game;
- добавлена лёгкая анимация сцены и снега;
- фон встроен в `index.html`, отдельные ассеты не обязательны;
- Cloudflare, Worker, Wrangler и Three.js CDN не используются.

Загружать только `index.html` в корень `main`.
