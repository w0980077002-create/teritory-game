# Territory — Sdolars / s7

GitHub-only версия.

`index.html` — единственный файл игры. Сцена Sdolars теперь полностью самодостаточная: внешний Three.js CDN удалён, поэтому отсутствие CDN в Telegram WebView не ломает запуск сцены.

Внутри сохранены Telegram Web App API, localStorage, тактический бой, инвентарь, рынок, районы, квесты, казино, гильдия и RU/EN.

Загружать `index.html` прямо в корень `main`.
