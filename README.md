# Territory S36

База S35.
Районы Sdolars теперь вынесены в полноценный игровой экран, а не только в скрытое модальное окно.
6 районов: Центральный, Старый порт, Крепость, Торговый квартал, Таверны, Промзона.
Переходы и текущий район сохраняются в localStorage.
Cloudflare/Worker/Wrangler не используются.
