# Territory Home V2

Home-screen refinement based on the agreed mobile-RPG reference direction.

## Included
- Vertical mobile-first composition for Android/iPhone proportions.
- Sdolars city remains the dominant visual object.
- Compact player profile and real HP display sourced from existing game state.
- Compact quest block and daily bonus.
- Game button uses a die and shows `5 игр`.
- Separate quick access to PvE, Arena, Inventory and Game.
- Existing Arena code is not modified.
- Existing Clan/Arena systems are not redesigned in this package.
- Existing Monopoly/Game code is preserved.
