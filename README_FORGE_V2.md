# TERRITORY FORGE V2

Полноэкранная изолированная кузница. Старый экран «Рынок снаряжения» больше не используется кнопкой «Кузница».

Что проверить:
1. Город → Кузница.
2. Должен открыться отдельный экран кузницы, город полностью скрыт.
3. Купить Боевой топор за 300 🪙.
4. Он появляется в «Мой арсенал».
5. Нажать «Экипировать».
6. В профиле урон должен стать +12, оружие — «Боевой топор».

Заменять весь комплект ZIP. Arena/backend не изменены.
