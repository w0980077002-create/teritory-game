# TERRITORY — LIVE HOME HUD PASS 01

## Что обнаружено
`home-master.png` — не чистый фон. Внутри самого изображения уже нарисованы значения `Lv. 78`, `VIP 6`, `45.0K`, `4.5K`, `125/200`, `6850/6850`, уровни экипировки, XP и другие показатели.

Поэтому серверный reset мог сработать, а экран всё равно показывал старые цифры: браузер просто рисовал их из картинки.

## Что делает этот pass
Добавляет один динамический слой поверх существующего `home-master.png`. Он не меняет навигацию, боевые экраны, Arena, PvE, Telegram auth или сервер.

Слой берёт значения из `TerritoryStore.state`:
- Level / VIP
- coins / gems / red gems
- energy
- HP
- XP
- chapter / stage / progress
- уровни первых 6 предметов экипировки
- первые 4 боевых расходника

Статическая картинка и её кнопки остаются на месте. Меняются только показатели.

## Важно
Это именно исправление отображения. Сервер reset остаётся отдельным механизмом. Если сервер отдаёт Level 1 / VIP 0 / 0 coins / 0 gems, домашний экран теперь должен показывать эти значения вместо нарисованных в картинке старых значений.
