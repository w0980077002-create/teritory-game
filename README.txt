TERITORY GAME — ARENA PUBLIC v32

Публичная версия Арены без упоминаний ботов/ботовского подбора в интерфейсе.

ЗАМЕНИТЬ:
- arena.js

arena.css можно оставить из v31.

Убрано из видимой Арены:
- «боты»;
- «подстановка ботов»;
- «если очередь пуста...»;
- технические формулировки про пул соперников.

Вместо этого игрок видит обычный подбор соперника по уровню/рейтингу.

Также сохранено:
- 1×1;
- 3×3;
- CHAOS;
- профили бойцов;
- классы;
- рейтинг;
- история;
- бой и тактики;
- награды.
