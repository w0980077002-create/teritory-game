S93 — БОЕВАЯ СЦЕНА
===================

Добавлен отдельный слой боевой сцены в стиле выбранного референса:
- персонажи непосредственно на поле;
- анимация удара;
- эффекты КРИТ / УКЛОНЕНИЕ / ПОБЕДА;
- номер хода;
- сообщение последнего события;
- работает поверх существующего тактического PvP.

Файлы:
- s93-battle-scene.png — визуальный фон сцены;
- s93-battle-scene.js — слой сцены.

Подключение:
<script src="s93-battle-scene.js?v=93"></script>

Открытие:
window.openTerritoryS93(match)

S93 не удаляет существующие S86/S91/S92 системы.
