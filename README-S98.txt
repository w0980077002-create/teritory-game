TERRITORY S98 — COMPACT BACKPACK

Что добавлено:
- Компактный мобильный рюкзак вместо огромной панели.
- Сетка предметов 3 колонки (2 на очень узком экране).
- Фильтры: Все / Оружие / Броня / Пояса.
- Количество предметов.
- Отметка экипированных вещей.
- Карточка выбранного предмета со статами.
- Экипировать / Снять / Продать / Выбросить.
- Баланс монет.
- Новый безопасный API /api/equipment/drop: нельзя выбросить экипированный предмет.
- index.html не изменяется.

Подключение UI:
<script src="s98-backpack.js"></script>
<button onclick="openTerritoryS98(playerId)">🎒</button>

Сервер:
1. Распаковать s98/apply-s98.js рядом с server.js.
2. Запустить: node apply-s98.js
3. Перезапустить сервер.
Перед изменением создаётся server.js.s97-backup.

Важно:
- Это готовый S98-патч к текущей серверной архитектуре Territory.
- В GitHub автоматически ничего не отправляется.
