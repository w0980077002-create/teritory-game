TERRITORY S100 — QUEST CENTER

Добавлено:
- компактный центр заданий для мобильной игры;
- прогресс каждого задания;
- награда XP и монетами;
- получение награды прямо из интерфейса;
- использует существующие /api/quests и /api/quests/claim;
- не изменяет index.html и не заменяет существующий сервер.

Подключение:
<link rel="stylesheet" href="s100-quests.css">
<script src="s100-quests.js"></script>

Открытие:
openTerritoryS100(playerId)

S100 рассчитан на текущую систему S89 квестов/прогрессии.
