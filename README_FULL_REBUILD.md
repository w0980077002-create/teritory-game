## Что заменить

Загрузи **все файлы из этого архива** в корень репозитория `teritory-game` с заменой одноимённых файлов.

Главное изменение:
- старый baked-touch bridge G141–G146 удалён;
- главный экран собирается HTML/CSS/JS;
- кнопки больше не зависят от координат картинки;
- добавлен отдельный игровой зал;
- ежедневный бонус работает отдельно;
- нижняя навигация сохранена;
- Arena/Game/Market/Districts/Inventory подключаются через существующий `showScreen`.
