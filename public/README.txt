Territory — Sdolars s25

Основа: s24.
Главная задача версии: перейти от локального прототипа к серверному сохранению прогресса, не ломая текущий интерфейс.

Добавлено:
- server.js: HTTP-сервер игры + WebSocket-чат;
- /api/health — проверка сервера;
- /api/player/<id> — сохранение/загрузка состояния игрока;
- players.json — постоянное серверное хранилище прототипа;
- синхронизация прогресса с Telegram user id (если игра открыта в Telegram);
- fallback на локальный player id для обычного браузера;
- глобальный и клановый чат сохраняются как раньше.

Запуск:
npm install
npm start

Открыть: http://localhost:3000

Для Telegram/Web App нужен HTTPS при размещении в интернете. Для настоящей защиты аккаунтов позже добавим серверную проверку Telegram initData.

Следующий большой этап после s25: полноценные игроки на сервере, PvP между двумя устройствами, гильдии и постоянная база данных.
