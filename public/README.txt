# TERRITORY — FIXED READY VERSION

Это готовая статическая версия игры без React/Vite-зависимостей.
Она специально сделана так, чтобы открываться прямо из папки `public` на существующем сервере.

## Что заменить в GitHub

В существующем репозитории `territory-game` замени в папке `public` ТОЛЬКО:
- index.html
- app.js
- style.css

Старые версии этих трёх файлов можно удалить и загрузить новые.

## Важно

Эта версия НЕ требует:
- npm install
- сборки Vite
- React
- Tailwind
- дополнительных библиотек

Поэтому белый пустой экран из-за неправильной Vite-сборки исчезает.

## Уже работает

Главная, чат, Магазин, покупка вещей, Инвентарь, Надеть/Снять,
Персонаж, очки характеристик, Арена, 3 бота, бой Удар/Блок,
критические удары, уклонения, награды, опыт, уровни, дроп,
Окраина, случайный враг, Госпиталь, Банк, сохранение в localStorage
и запуск внутри Telegram WebApp.

## Telegram

Telegram WebApp API вызывается автоматически, если приложение открыто внутри Telegram.
В обычном браузере игра тоже работает.
