# SDOLARS — Territory

Готовый автономный прототип RPG, который открывается прямо в браузере телефона.

## Запуск
1. Распакуйте ZIP.
2. Откройте `index.html` в браузере.
3. Игра работает без сервера и сохраняет прогресс в `localStorage`.

## Что уже работает
- Главный экран города Sdolars.
- Кнопки города, героя, инвентаря, экипировки, заданий.
- Магазин: покупка предметов.
- Инвентарь: предметы и использование зелий.
- Кузница: улучшение оружия.
- Таверна: найм союзника.
- Пошаговый бой с несколькими действиями.
- Здоровье, атака, защита, XP, уровни.
- Золото, кристаллы, энергия.
- Задания и награды.
- Ежедневная награда с таймером.
- Сохранение прогресса на устройстве.

Это первая готовая игровая сборка. Дальше можно заменить временную иконку героя на отдельный полноценный sprite/арт, добавить реальные локации, противников, серверную базу данных и Telegram Mini App.
