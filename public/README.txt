TERITORY — готовая фронтенд-версия

Файлы:
- index.html — интерфейс
- style.css — дизайн
- app.js — логика игры

Запуск:
1. Положи все 3 файла в одну папку.
2. Открой index.html в браузере для теста.
3. Для Telegram Mini App размести папку на HTTPS-хостинге.
4. В BotFather укажи URL Web App.

Важно:
- Сохранение сейчас работает через localStorage браузера.
- Для настоящей многопользовательской игры нужен сервер/БД. Его можно подключить следующим этапом.
- Внешние картинки не обязательны: иконки сделаны через emoji, чтобы игра сразу запускалась без папки assets.
