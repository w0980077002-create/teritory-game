TERRITORY — классический UI главной страницы

Заменяет современную сетку плиток на стиль старых браузерных игр 2000-х:
- крупная локация;
- текстовая навигация;
- список «Куда пойти»;
- компактные HP / энергия / золото;
- постоянно видимый игровой чат;
- мобильная версия;
- совместимо с Telegram WebApp.

Файлы:
- index.html
- style.css
- app.js

Важно:
Этот пакет меняет именно фронтенд главной страницы. Сервер, базу данных и Telegram-подключение не трогает.
Чат в этой версии локальный (сообщения живут в текущей открытой странице). Для общего чата между игроками нужно подключить сервер/WebSocket/API.
