TERRITORY — SDOLARS / VERSION 1

Это полноценная мобильная HTML-игра-прототип, а не растянутая фотография.

Главный экран:
- город Sdolars;
- верхняя панель героя и ресурсов;
- задание;
- ежедневный бонус;
- кузница, таверна, магазин;
- бой, инвентарь, экипировка, задания;
- награды;
- нижняя навигация.

Игровые экраны:
- Герой с характеристиками;
- Инвентарь с надеванием/выбрасыванием предметов;
- Экипировка;
- Магазин с покупками;
- Кузница с улучшением;
- Таверна;
- Задания с наградой;
- Сообщения, достижения, настройки, гильдия, события, VIP;
- Тактический бой: зона атаки + две зоны защиты + ход противника.

Прогресс хранится в localStorage.

Запуск:
1. Распаковать ZIP.
2. Открыть index.html.
3. На телефоне можно открыть через браузер/локальный HTML-просмотрщик.

Для следующего этапа можно подключить Telegram Web App, сервер, аккаунты и сетевые PvP-бои.
