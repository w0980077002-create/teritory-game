Territory — Sdolars s13

В этой версии s11 оставлена базой интерфейса, а чат подключён к WebSocket-серверу.

Запуск:
1. Установить Node.js 18+.
2. В папке проекта выполнить: npm install
3. Запустить: npm start
4. Открыть http://localhost:3000

Для Telegram Mini App сервер должен быть доступен по HTTPS. Тогда игра автоматически использует wss:// для чата.

Чат:
- Общий чат и чат клана.
- 10 смайликов.
- Онлайн-список.
- Сообщения видят все подключённые игроки в выбранной комнате.
- История последних сообщений хранится на сервере до перезапуска.
