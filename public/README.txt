
TERITORY — WORKING BUILD

Что внутри:
- Node.js + Express
- WebSocket онлайн-чат и онлайн-счётчик
- Сервер хранит персонажей в data/players.json
- Сервер сам считает покупки, экипировку, лечение, бои и казино
- Telegram Mini App авторизация через initData с проверкой HMAC
- Локальный ДЕМО-режим для теста без Telegram
- Персонаж, инвентарь, экипировка, магазин, арена, мир, казино, игроки, чат
- Анимации боя и слотов
- Адаптация под телефон

ЗАПУСК:
1. Установить Node.js 18+
2. В папке проекта:
   npm install
   npm start
3. Открыть:
   http://localhost:3000
4. Для локальной проверки нажать "ДЕМО-РЕЖИМ".

TELEGRAM:
1. Создать бота через @BotFather.
2. Для настоящей авторизации задать переменную окружения BOT_TOKEN.
3. Разместить проект на HTTPS-домене.
4. В Telegram настроить Mini App URL на адрес проекта.
5. Открыть Mini App из Telegram — регистрация и пароль НЕ нужны.

ВАЖНО:
- Казино использует только виртуальные монеты.
- Для настоящего продакшена рекомендуется PostgreSQL/Redis, резервные копии, rate limiting, отдельная авторизация с ротацией сессий и HTTPS reverse proxy.
- Этот архив не требует базы с нативными модулями и подходит для простого запуска на сервере/Termux.
