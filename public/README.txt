Основа: рабочая версия V4/s1.
Главная страница не переработана.

Добавлено в s2:
- Telegram WebApp identity: ник игрока берётся из Telegram (username, иначе имя/фамилия).
- Фото игрока берётся из Telegram photo_url, если Telegram его передал.
- Если фото Telegram недоступно, используется новый взрослый Viking-аватар.
- В игре остаётся резервный аватар, поэтому standalone-запуск тоже работает.

Важно: без серверной базы это отображает профиль текущего игрока. Для общего списка всех игроков одновременно нужен сервер/БД.
