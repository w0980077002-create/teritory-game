Territory — Sdolars GAME
Главный экран собран по предоставленному референсу, но интерфейс является настоящим HTML/CSS/JS.
Иконки и фон встроены локально, кнопки работают, есть разделы героя/инвентаря/экипировки/заданий/кузницы/магазина/таверны и тактический бой.
Оптимизировано под мобильный экран: иконки компактные, кнопки остаются удобными для касания.
Запуск: открыть index.html.
