Territory — Sdolars s27

База: s26.

Что добавлено в s27:
- На главном экране города теперь ВИДЕН блок «ИГРОКИ ОНЛАЙН».
- Показывается LIVE/OFFLINE статус сервера.
- Видны другие игроки, пришедшие через WebSocket.
- У каждого игрока есть кнопка «ДУЭЛЬ».
- Кнопка «ВСЕ» открывает чат/список игроков.
- Вызов на PvP отправляется прямо из города.
- Существующий интерфейс города и компактная кнопка «Бой» сохранены.
- Серверный PvP из s26 сохранён.

Запуск:
npm install
npm start
