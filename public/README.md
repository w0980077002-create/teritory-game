# TERITORY — Classic RPG 2004

Полностью играбельная локальная версия браузерной RPG.

## Запуск
1. `npm install`
2. `npm run dev`
3. Откройте адрес Vite.

Для GitHub Pages:
- `npm install`
- `npm run build`
- публикуйте папку `dist`.

## Что реализовано
- Центральный район, Магазин, Арена, Окраина, Госпиталь, Банк.
- Магазин с 4 предметами, покупкой за Ria и проверкой уровня/баланса.
- Инвентарь с Надеть/Снять.
- Оружие добавляет урон, броня увеличивает максимальный HP.
- Арена с 3 ботами и наградами.
- Пошаговый бой: один удар + один блок из связанных зон.
- Случайный удар/блок бота.
- 10% крит и 10% уклонение.
- Победа выдаёт опыт/Ria и шанс дропа.
- Уровень повышается каждые 100 опыта, +3 очка характеристик.
- Персонаж: Сила, Ловкость, Выносливость и прокачка.
- Чат с немедленным добавлением сообщений и кликом по нику для обращения.
- Автосохранение прогресса в localStorage.

## Сброс
Кнопка «Сбросить сохранение» удаляет локальный прогресс и начинает игру заново.
