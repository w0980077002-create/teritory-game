# Territory Classic RPG

Готовая браузерная RPG в стиле старых текстово-графических игр 2000-х.

## Возможности
- Центральная площадь, Магазин, Арена, Госпиталь и Окраина.
- Классическая навигация ссылками вместо сетки карточек.
- Игровой чат с локальным состоянием.
- Персонаж и распределение характеристик.
- Инвентарь и экипировка.
- Покупка предметов за Ria.
- Пошаговый бой: Strike (1 зона) + Block (2 связанные зоны).
- 10% Crit, 10% Evade, блок с уроном 0/1.
- Боты и симулированный PvP.
- Награды: +20 Exp, +15–30 Ria, 20% шанс предмета.
- Окраина случайно создаёт противника.
- Госпиталь восстанавливает HP/Energy.
- TailwindCSS подключён через @tailwindcss/vite.
- Работает как обычный Vite/React проект и может быть встроен в Telegram WebApp.

## Запуск

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run preview
```

## Важно
Состояние сейчас хранится в памяти React, поэтому после обновления страницы прогресс сбрасывается. Чат также локальный. Для настоящего multiplayer нужны сервер, БД и WebSocket/API.
