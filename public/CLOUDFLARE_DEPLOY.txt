TERRITORY SDOLARS s29 — РЕАЛЬНЫЙ СЕРВЕР

1) Открой папку s29.
2) Установи зависимости:
   npm install
3) Авторизуй Cloudflare:
   npx wrangler login
4) Добавь секрет Telegram-бота:
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   Никому не отправляй этот токен и не вставляй его в код.
5) Локально:
   npm run dev
6) Опубликовать:
   npm run deploy

Cloudflare Workers + Durable Objects + SQLite используются как сервер игры. Durable Objects предназначены Cloudflare для realtime-приложений и multiplayer games, а SQLite — рекомендуемое хранилище для новых Durable Objects.

Проверка:
https://ВАШ-ДОМЕН/api/health
Ожидается JSON с ok:true и version:s29.

После публикации открой Mini App именно через HTTPS URL Worker. Telegram initData будет проверяться сервером.
