S95 — ОРУЖИЕ + БОЕВЫЕ ЭФФЕКТЫ
================================

Добавляет к объединённому PvP:
- оружие в руках персонажей;
- меч;
- топор;
- кулаки;
- щит/броню;
- эффект взмаха оружием;
- эффект попадания;
- эффект критического удара;
- эффект уклонения;
- эффект блока;
- эффект победы/поражения.

Слой работает поверх S94 и не заменяет index.html.

Порядок:
S92 → S93 → S94 → S95

Открытие:
window.openTerritoryS95(match)

Примечание:
В текущем серверном pvpPublic экипировка не передаётся в объекте
attacker/defender. Поэтому S95 имеет безопасные визуальные значения
по умолчанию. Для полного соответствия конкретному оружию следующий
серверный шаг должен добавить equipment в pvpPublic.
