S85 — тактический бой Territory

Добавляет отдельный мобильный экран тактического PvP:
• 4 зоны: Голова / Грудь / Пояс / Ноги
• 1 зона атаки
• 2 зоны защиты
• HP двух бойцов
• журнал ходов
• вызов и принятие боя
• автообновление матча каждые 3 секунды

Подключение:
<script src="s85-tactical.js?v=85"></script>

ВАЖНО:
Текущий сервер в GitHub уже принимает zone и defense, но его текущая формула использует defense как одну строку. Для полноценного механического эффекта двух блоков следующий серверный патч должен проверять массив/две зоны защиты. UI S85 уже отправляет обе зоны через "zone1,zone2".
