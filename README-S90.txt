S90 — ПРОКАЧКА ПЕРСОНАЖА
==========================

Добавлено:
- Сила
- Ловкость
- Свободные очки
- +2 свободных очка за каждый новый уровень
- прокачка силы/ловкости через API
- сброс распределённых очков
- лимит характеристики 100

Реальное влияние:
Сила:
- увеличивает урон;
- усиливает шанс критического удара.

Ловкость:
- формирует шанс уклонения;
- увеличивает расчёт максимального HP.

API:
GET  /api/character?id=PLAYER_ID
POST /api/character/upgrade {stat:"strength"|"agility",count:1}
POST /api/character/reset-points

Патч сохраняет существующую экономику, задания, экипировку,
гильдию и PvP. Перед изменением server.js создаётся
server.js.s89-backup.
