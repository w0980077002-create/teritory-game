TERRITORY FORGE V7 — GLOBAL UI SYSTEM

Что изменено:
- Все обычные крестики окон приведены к одному стилю: маленький чёрный круг + белый ×.

- Единая touch/pointer обработка для профильных, кузницы и игровых окон.
- MutationObserver автоматически применяет систему к динамически созданным окнам.
- Arena исключена из системы и не изменялась.
- Backend не изменялся.

Установка:
1. Замени файлы проекта содержимым ZIP.
2. Commit.
3. Дождись Render Deploy.
4. Полностью закрой Telegram Mini App и открой заново.
5. Проверь кузницу, профиль и игровые окна.
