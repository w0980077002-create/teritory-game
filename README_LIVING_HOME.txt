TERRITORY — LIVING HOME PASS 01
================================

This pass adds a first living-home layer without replacing the canonical
PvE, Arena, Store, Followers or combat-item systems.

Added:
- subtle moving snow, wind, moonlight and campfire glow;
- an animated hero and active follower on the home screen;
- hero tap opens Hero;
- follower tap opens a small info panel;
- follower visual updates from Followers.activeFollower;
- name/level/follower nameplate reads TerritoryStore state.

Files to overlay:
- index.html
- home-life.js
- home-life.css

The existing navigation/home-rebuild files are expected to be the repaired
versions already in the repository.

This is intentionally a visual/interaction pass. It does not claim that
every future game system is complete.
