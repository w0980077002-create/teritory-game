S88 — ЭКОНОМИКА + РЫНОК
========================

Добавляет связку:
рынок → покупка → монеты → рюкзак → экипировка → продажа.

Каталог:
- Железный меч — 250 / продажа 125
- Викингский топор — 450 / продажа 225
- Стальная броня — 600 / продажа 300
- Кожаный пояс — 180 / продажа 90

API:
GET  /api/market
GET  /api/economy?id=PLAYER_ID
POST /api/market/buy     {itemId, qty}
POST /api/market/sell    {itemId, qty}
POST /api/economy/reward {amount}

Перед изменением server.js создаётся server.js.s87-backup.

Важно:
S88 не заменяет index.html и не удаляет существующие системы.
Для существующих игроков монеты автоматически получают значение 1000,
если поле coins ещё отсутствует.
