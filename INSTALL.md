# TERRITORY COMPLETE PASS — 2026-09-30

Этот пакет рассчитан на текущую ветку игры, которую мы проверили по видео и по
репозиториям.

## Что входит

1. `index.html` — версия с подключением Complete Pass.
2. `territory-complete-pass-2026-09-30.js` — интеграция боевых камней,
   полноценной лавки, покупок, гостевого Render-теста и общей навигации.
3. `territory-complete-pass-2026-09-30.css` — визуальная часть.
4. `territory-live-arena-bridge.js` — новый live Arena UI с:
   - защита 2 зоны;
   - атака 1 зона;
   - Удар;
   - Автобой;
   - история;
   - чат игроков;
   - выход/сдаться.
5. `SERVER_PATCH_WORKER.diff` — серверные изменения для реальных боевых
   камней, ежедневного входа и чата live Arena.

## Что должно измениться

### Арена
- кнопки зон реально реагируют;
- Удар становится доступным после выбора тактики;
- Автобой сам выбирает защиту/атаку и делает ход, когда ход игрока;
- live Arena получает общий чат;
- нижняя навигация использует ту же панель, что и главный экран.

### Боевые камни
- на главном экране появляется пятая кнопка слева от x2;
- счётчик показывает канонический `battleStones`;
- Render без Telegram получает один тестовый запас 30 камней, чтобы можно
  было проверять бой;
- Telegram-игрок получает камни через ежедневный вход, задания, босса и
  покупку за алмазы;
- реальные деньги не имитируются.

### Лавка
Есть категории:
- Эликсиры
- Оружие
- Броня
- Аксессуары
- Боевые

У товара есть:
- иконка;
- название;
- описание;
- цена;
- кнопка покупки.

Покупки идут через существующие серверные endpoint'ы.
