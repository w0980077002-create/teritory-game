TERRITORY — LIVING HOME PASS 05

Overlay for the current Territory main screen.

Changes:
- Keeps follower on the LEFT of the hero and slightly behind.
- Adds a subtle living ground/rune layer under the characters.
- Adds a world pulse for damage, healing, rewards, level-up and taps.
- Adds automatic reaction detection from TerritoryStore state changes for HP, level and resource gains, so feedback can work even when a custom event is not emitted.
- Adds a small transition when the active follower changes.

Install:
1. Unzip over the current Territory folder and replace the files when asked.
2. Do not delete canonical game modules.
3. Refresh the Telegram WebApp.

This is an additive visual layer; it does not replace combat logic.
