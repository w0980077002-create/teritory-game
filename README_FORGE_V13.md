TERRITORY FORGE V13 — GLOBAL ACTION BUTTONS

Что изменено:
- Единый стандарт основных действий: Купить, Экипировать, Сменить, Получить, Подтвердить и аналогичные действия.
- Единый размер, золотая рамка, тёмная кнопка, touch-safe зона и active-состояние.
- Магазин V12 входит в систему автоматически.
- Обычные модалки и кузница используют тот же стандарт.
- Arena не стилизуется этим глобальным слоем и не изменялась.
- Backend не изменялся.

Установка:
1. Замени файлы содержимым ZIP.
2. Commit.
3. Дождись Render Deploy.
4. Полностью закрой Mini App и открой заново.
5. Проверь Магазин, Кузницу и Профиль: основные кнопки должны выглядеть единообразно.
