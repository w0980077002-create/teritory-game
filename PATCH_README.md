# Territory Game — reference UI patch

Replace these files in the repository:
- index.html
- reference-ui.css
- reference-ui.js

The patch adds a mobile inventory screen styled from the supplied reference:
ornate header, central socket, circular gem items, horizontal equipment rows,
selected-row highlight, and fixed bottom back control.

The existing game state, Telegram profile, inventory/weapon data and home screen
remain in place. No original artwork file is replaced by this patch.
